# ExplosionBox

# 制作担当

プランナー　阿部直哉

プログラマー　伊與颯太

# ゲームの遊び方

stageにある箱から一つ選択し、爆弾のある箱を選ばないように箱の上に表示されているポイントとを獲得して、いずれかの箱に１つの爆弾を設置していくのをプレイヤーとCPUが交互に行うゲームです。

# ゲームルール

選んだ箱に爆弾がなかった場合に箱の上のポイントが自分のポイントに加算されます。
もし爆弾があった場合にライフが１減り、自分のポイントがすべてなくなります。

# 勝利条件

爆弾を設置し、相手のライフを先に０にするか、ターン終了時か箱が一つになった時点でポイント数が相手よりも多ければ勝ちになります。
